## Agent skills

### Issue tracker

Issues live in GitHub Issues for `jacobdrury/reviewdesk` (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.

### UI performance

Snappy scroll, layout, and disclosure for Overview, Diff, Inbox, and any scrollable pane. Read `docs/agents/ui-performance.md` before making those choices.
